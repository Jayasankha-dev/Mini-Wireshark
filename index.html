Engineered For Performance

Packed with enterprise-level features built natively inside Windows PowerShell environment.

Background Capture Engine

Uses isolated PowerShell Runspaces and Raw Sockets (ReceiveAll) to capture live traffic without lagging the UI.

Virtual ListView Mode

Capable of rendering 10,000+ packets smoothly with zero memory bloating or lag using direct memory arrays.

Thread-Safe Architecture

Implements ConcurrentQueue and synchronized hashtables to prevent thread race conditions seamlessly.

Background Pre-Filtering

Filters keywords dynamically inside the background runspace before items reach the UI queue, minimizing load.

Hex & ASCII Payload Dump

Generates detailed packet footprints with side-by-side Hexadecimal and ASCII previews for deep analysis.

CSV Export & Import

Save captured sessions along with full payload details for offline forensics or sharing with teammates.

System Requirements

  • OS: Windows 10 / 11 (64-bit recommended) or Windows Server.
  • Privileges: Must be run with Administrator privileges (required for binding raw sockets/network interfaces).
  • PowerShell: Version 5.1 or higher.

Quick Start

  1. 1 Download and extract the MiniWireshark.7z package.
  2. 2 Open PowerShell as Administrator.
  3. 3 Select your active network adapter and click "Start Capture".
